# 問題の元資料

このディレクトリの7つのテキストは、提供された元ファイルをそのまま保存したものです。アプリには `app/src/main/assets/quiz.json` として、7カテゴリ・計80問を収録しています。選択肢の順序と正解を維持し、解答画面の解説欄には正解を示しています。アニメ・映画の問題は提供されていないため含みません。

取り込み時には次の表現を調整しています。

- 地理 Q3: 死海の水位は変化するため、数値を「海面下400mより低い」とした（[米国地質調査所](https://eros.usgs.gov/earthshots/dead-sea-israel-jordan-west-bank)）。
- 地理 Q10: 河川本流が流れる国の数と流域を共有する国の数を区別し、設問を明確にした（[ICPDR](https://www.icpdr.org/danube-basin/danube-river-basin/danube-river-basin-overview-map)）。
- 理科・科学の後半 Q3: 月の公転周期を問う文の助詞を修正した。Q6: 火成岩の範囲を正しく表すよう、噴火に限らない表現にした（[米国地質調査所](https://www.usgs.gov/faqs/what-are-igneous-rocks?page=0)）。
- 業界用語 Q1: スプリント期間を「1か月以内」とした（[Scrum Guide](https://scrumguides.org/scrum-guide.html)）。
- 英単語 Q4: 通信帯域を単位時間あたりのデータ量として補足した。Q5: deprecated は将来廃止が確定しているとは限らないため「使用を勧められない」とした（[MDN](https://developer.mozilla.org/en-US/docs/MDN/Writing_guidelines/Experimental_deprecated_obsolete)）。
