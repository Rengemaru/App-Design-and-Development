# クイズ帳 スペック（仕様書）

Androidクイズゲーム「クイズ帳」の仕様をまとめる。実装・テスト・レビューの基準とする。
画面の見た目は `docs/wireframe/`、動作確認は `docs/mock/` を参照。数値はすべて設定値として1か所に集約する。

- 対象端末: Android / 言語: Kotlin / 環境: Android Studio
- 基準レイアウト: 360 × 800 dp（縦）、左右余白 16dp、タップ部品は高さ 48dp 以上

## 1. 画面と遷移

| 画面 | 主な要素 |
| --- | --- |
| ホーム | タイトル「クイズ帳」/ スタートボタン |
| カテゴリ選択 | カテゴリカード（アイコン・名前・問題数）/ 戻る。0件時は空状態＋追加 |
| 問題 | ヘッダー(タイトルへ/Q◯ of N/スコア) / 進捗バー / 連続正解 / カウントダウン / 問題カード(画像任意) / 選択肢A〜D / ヒント(時間切れ時) |
| 答え | ○×判定 / 正解の選択肢 / 解説 / 連続正解ボーナス / 時間ボーナス / 次へ(自動送り) |
| 結果 | ランク / 次ランク案内 / 最大連続・ボーナス・タイム / 合計スコア / タイトルへ・もう一度 |

```
ホーム →(スタート)→ カテゴリ選択 →(カテゴリ選択)→ 問題
問題 →(選択肢)→ 答え →(次へ/自動)→ 問題 or 結果
結果 →(タイトルへ)→ ホーム / (もう一度)→ 同カテゴリの問題1
戻り: カテゴリ選択→ホーム、問題・答えの「タイトルへ」→ホーム
```

## 2. スコア

正解時のみ加点する。

| 要素 | 計算式 | 上限 |
| --- | --- | --- |
| 基礎点 | `100`（固定） | 100 |
| 連続正解ボーナス | `(連続数 − 1) × 15` | 上限なし |
| 時間ボーナス | `round(残り秒数 × 0.5)` | +10（20秒満タン時） |

- 不正解は加点なし（基礎点も0）で、連続正解はリセットされる。
- 合計スコアには連続・時間ボーナスを含める。

## 3. 制限時間・ヒント

- 1問ごとに制限時間 **20秒**（設定値）のカウントダウン。残り時間でバーの色が変化する。
- **0秒になっても解答は継続できる**。時間切れは「時間ボーナスが+0になるだけ」で、正誤判定・連続正解には影響しない。
- 制限時間が **0秒になったとき（未解答時）だけ**、その問題のヒントを表示する。秒数が残っているうちは表示しない。
- ヒント文は問題ごとに設定する（未設定なら非表示でよい）。

## 4. ランク

**ランク = 獲得スコア ÷ 理論最大スコア** で決める。
理論最大 = 全問正解・時間ボーナス満タン・連続正解が最後まで続いたときのスコア。

```
理論最大 = Σ(i=1..N){ 100 + 10 + (i-1)×15 }   // 5問なら 700pt
```

| ランク | スコア比 | 5問(理論700pt)の目安 |
| --- | --- | --- |
| S | 92%以上 | 644pt以上 |
| A | 80%以上 | 560pt以上 |
| B | 60%以上 | 420pt以上 |
| C | 40%以上 | 280pt以上 |
| D | 40%未満 | 280pt未満 |

- Sを92%にしているのは、全問正解なら時間ボーナス0でもスコア比が約92.9%になり、**正解を取りきればSを狙える**ようにするため。時間は上乗せ要素。
- ボーナスはスコアの一部なのでランクにも反映される。
- **5問未満**はランクを出さず「◯問せいかい」の表示のみ。

## 5. 答え画面の自動送り

- 答え画面表示後、**3秒**（設定値）のカウントダウンで自動的に次へ進む。
- ボタン内に残り秒数を表示し、**手動タップでも即座に**進める。
- 最終問題でも同じ秒数で**自動的に結果画面へ**進む。
- 画面を離脱（タイトルへ等）した場合は自動送りを停止する。

## 6. 設定値一覧（1か所に集約）

| 名前 | 既定値 | 意味 |
| --- | --- | --- |
| TIME_LIMIT | 20 | 1問の制限時間（秒） |
| TIME_COEF | 0.5 | 時間ボーナス = 残り秒数 × 係数 |
| BASE_POINT | 100 | 正解の基礎点 |
| COMBO_STEP | 15 | 連続正解ボーナスの刻み |
| MIN_Q_FOR_RANK | 5 | ランクを出す最小問題数 |
| AUTO_ADVANCE_SEC | 3 | 答え画面の自動送り秒数 |
| ランク閾値 | 0.92 / 0.80 / 0.60 / 0.40 | S / A / B / C の下限 |

## 7. 受け入れ条件（抜粋）

- [ ] カテゴリを選ぶと、そのカテゴリの問題1から開始する。
- [ ] 正解で基礎点・連続正解ボーナス・時間ボーナスが加算される。
- [ ] 不正解では加点されず、連続正解がリセットされる。
- [ ] 時間切れ(0秒)でも解答でき、正解すれば連続正解は継続する。時間ボーナスのみ0。
- [ ] 時間が残っているうちはヒントが表示されない。0秒で（未解答時のみ）ヒントが表示される。
- [ ] ランクはスコア比で決まり、全問正解なら時間0でもSになる。
- [ ] 問題数が5未満のときはランクを出さない。
- [ ] 答え画面は既定3秒で自動的に次へ進み、手動でも進める。最終問題では結果へ進む。
- [ ] もう一度は同じカテゴリを最初から始める。
